# دليل تشغيل تطبيق الخطة التشغيلية خارج Claude

النسخة الخارجية هي نفس التطبيق، لكن بياناتها في Firebase، فلا تحتاج المسؤولات إلى حساب Claude أو GitHub. يدخلن برمز المدرسة ثم يخترن أسماءهن.

## ١) إنشاء مشروع Firebase
1. ادخلي إلى https://console.firebase.google.com بحساب Google الخاص بالمدرسة.
2. اضغطي **Add project** واختاري اسمًا مثل `khutta-1448`، ويمكنك إيقاف Google Analytics.

## ٢) تفعيل تسجيل الدخول
1. من القائمة: **Build ← Authentication ← Get started**.
2. في تبويب **Sign-in method** فعّلي **Email/Password**.
3. في تبويب **Users** أضيفي مستخدمَين:
   - `staff@khutta.app` وكلمة مروره هي **رمز المدرسة** الذي ستعطينه للمسؤولات (٦ خانات على الأقل).
   - بريدك أنتِ وكلمة مرور خاصة بك، وهذا حساب المشرفة.

## ٣) إنشاء قاعدة البيانات
1. **Build ← Firestore Database ← Create database**، واختاري موقعًا قريبًا مثل `me-central2` أو `eur3`.
2. في تبويب **Rules** ضعي هذا ثم **Publish**:
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
```
بهذا لا يقرأ البيانات أو يعدّلها إلا من دخل برمز المدرسة أو بحساب المشرفة.

## ٤) ربط التطبيق بالمشروع
1. من **Project settings** (رمز الترس) ← **Your apps** ← اضغطي رمز الويب `</>` وسمّيه `khutta`.
2. ستظهر لك إعدادات `firebaseConfig`. انسخي القيم إلى ملف **config.js** مكان النصوص المؤقتة (apiKey وauthDomain وprojectId وstorageBucket وmessagingSenderId وappId).
3. اكتبي اسمك في `adminName`.

## ٥) النشر على GitHub Pages
عند ربط حسابك في GitHub بالمشروع هنا، أتولّى أنا رفع الملفات وتحديثها مع كل تعديل في التصميم. وإن أردتِ النشر يدويًا:
1. أنشئي مستودعًا عامًا (Public) باسم `khutta-plan`.
2. ارفعي الملفات الثلاثة: `index.html` و`config.js` و`seed.js`.
3. **Settings ← Pages ← Branch: main ← Save**. بعد دقيقة يظهر الرابط، مثل `https://اسم-حسابك.github.io/khutta-plan/`.
4. في Firebase: **Authentication ← Settings ← Authorized domains ← Add domain**، وأضيفي `اسم-حسابك.github.io`.

## ٦) استيراد بيانات الخطة (مرة واحدة)
1. افتحي الرابط واضغطي **دخول المشرفة بالبريد الإلكتروني**، ثم ادخلي ببريدك.
2. ستظهر رسالة «لا توجد برامج بعد» مع زر **استيراد بيانات الخطة**. اضغطيه، فتُنقل البرامج العشرة والمهام الـ٩٤ بكل تعديلاتك.

## ٧) مشاركة الرابط مع المسؤولات
أرسلي لهن الرابط ورمز المدرسة. عند أول دخول تختار كل واحدة اسمها، فيُسجَّل مع كل تحديث وشاهد ترفعه.

## ملاحظات
- **الشواهد:** تُحفظ الصور مضغوطة داخل قاعدة البيانات، والحد ٧٠٠ كيلوبايت للملف، وهذا يكفي للصور وملفات PDF الصغيرة على الخطة المجانية. للملفات الأكبر استخدمن زر **إضافة رابط** (رابط Google Drive مثلًا).
- **الشواهد المرفوعة سابقًا في نسخة Claude** لا تنتقل تلقائيًا لأنها محفوظة في Claude، فتُرفع من جديد عند الحاجة.
- **تغيير رمز المدرسة:** من Authentication ← Users ← المستخدم `staff@khutta.app` ← Reset password.
- **الخطة المجانية (Spark)** تكفي المدرسة بسهولة: ٥٠ ألف قراءة و٢٠ ألف كتابة يوميًا.
